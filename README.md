## Локальная разработка RU / EN

Сайт поддерживает русский и английский языки. Изменения готовятся в отдельных ветках; публикация GitHub Pages выполняется из `main`.

Переводы находятся в `translations.js`, привязки — в `index.html` (`data-i18n` и `data-i18n-aria-label` / `data-i18n-content`). Статический HTML сохраняет русский текст. При редактировании RU синхронизируйте его со словарём. В строках допустимы только существующие элементы оформления: `span`, `strong`, `br`.

`app.js` выбирает язык: `?lang=ru` или `?lang=en` → сохранённый выбор → русский. Переключение сохраняет маршрут, фильтр и раскрытые проекты. Кнопки доступны на всех пяти маршрутах; стили находятся в `language.css`. Обе ссылки `[data-resume]` скачивают файл по текущему языку: RU — `assets/mark-zhdanov-resume.pdf`, EN — `assets/mark-zhdanov-resume-en.pdf`. Обе версии обновлены 30.10.2026: уточнены профиль, описание работы с ИИ-агентами и стадия агента для отчётности руководителю.

Для превью достаточно любого локального HTTP-сервера из корня репозитория. Ссылки: `/?lang=en#home`, `/?lang=ru#projects`. В текущем рабочем окружении используется порт 4174.


### Дата PDF при скачивании

Обе кнопки `[data-resume]` формируют файл в браузере: `app.js` сохраняет язык и локальную дату устройства в момент клика, `resume-pdf.js` заполняет поле `downloadDate` и превращает его в обычный текст. Шаблоны в `assets/mark-zhdanov-resume*.pdf` не содержат фиксированной даты. При прямом открытии этих URL или без JavaScript документ будет без даты скачивания. При ошибке подготовки кнопка предлагает повторить попытку.

`assets/pdf-lib-1.17.1.min.js` — локальная UMD-сборка pdf-lib 1.17.1, загружается только по запросу PDF. Лицензия MIT — `assets/LICENSE-pdf-lib.md`. Источник: https://github.com/Hopding/pdf-lib/tree/v1.17.1; копия взята из одноимённого пакета установленного runtime. Внешние CDN при работе сайта не используются.

Канонический локальный генератор шаблонов: `work/build_resume_blue.py` в исходном проекте портфолио. При пересборке сохранять поле `downloadDate` (однострочное, пустое, внизу страницы); без него скачивание с текущей датой завершится ошибкой. Обновление текста резюме по-прежнему выполняется отдельно, через `translations.js` и пересборку шаблонов.
